# Run it locally with:

`Node js` : 18+ `Jangan lupa NPM install kalau local`

   ```bash
   cp .env.example .env
   ```

`Isi value ENV sesuai kebutuhan`

**run:**
   ```bash
   node index.js
   ```
absen sekarang: `node index.js --now`
cek hari-libur: `node index.js --check-collision`
